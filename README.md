# The Fit Muslim — Lifestyle

> **Faith. Discipline. Strength.**

A premium Islamic + fitness lifestyle platform: an e-commerce store for Islamic
and productive/fitness products, a journal of faith-driven fitness content, and
a signature feature — personalised, **expert-approved diet & training plans**
built around your body and your deen.

Designed for the modern Muslim, sister and brother alike.

---

## ✨ Features

- **Editorial luxury design** — obsidian black, antique gold, and forest green,
  with a heraldic / old-world elegance achieved through restraint and space.
- **Cinematic hero** with atmospheric imagery and subtle motion.
- **The Store** — curated Islamic & fitness products.
- **Diet Plans** — intake → tailored plan → **admin approval** → delivery.
- **The Journal** — training, halal nutrition, and mindset content.
- **Community & membership.**

## 🛠 Tech Stack

| Layer | Choice |
|---|---|
| Framework | **Next.js 16** (App Router) + **TypeScript** |
| Styling | **Tailwind CSS v4** with custom design tokens |
| Motion | **Framer Motion** |
| Fonts | Playfair Display · Cormorant Garamond · Inter · Amiri |
| Planned | PostgreSQL + Prisma · Auth.js/Clerk · Stripe · Vercel |

## 🚀 Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## 📁 Structure

```
app/            App Router pages, layout, global styles
components/     Navbar, Hero, Philosophy, Pillars, FeaturedProducts,
                DietPlanFlow, Journal, Footer, Reveal
public/         Logo and static assets
```
